# The Creative Eye — Elika Valanejad

A standalone creative portfolio, separate from the interior architecture portfolio.

Built with HTML, CSS, and JavaScript. Original imagery and video are drawn from Elika’s Canva creative portfolio. Projects distinguish self-initiated concepts from freelance work.

## Preview

Serve this directory using any static web server. No build or dependencies are required.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select **main** and **/ (root)** and save. GitHub will display the live URL once deployment finishes.

## Edit

- `index.html`: introduction, about section, contact details.
- `app.js`: project content, galleries, filters, and video captions.
- `style.css`: layout, colours, and responsive styles.
- `assets/`: images and videos. Videos load only when requested.

Google Fonts is optional; system serif and sans-serif fallbacks are included. Project galleries use a native dialog with keyboard support. Reduced-motion preferences are respected.

## Original social feed artwork

The three `assets/*-original-feed.png` files preserve the finished layered compositions rendered from the original Canva portfolio. Keep these as complete artwork: do not replace their tiles with individual source images, recreate their typography, or recolour their patterns. The source portfolio is linked beside each feed.
